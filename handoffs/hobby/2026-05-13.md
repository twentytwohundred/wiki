### Chat substrate ... behavior fixes

Several bugs Doug caught immediately on first use:

- **History wipe on reply.** `MultiChatStore.listMessages` was returning only modern JSONL once any message landed, dropping legacy `chat.jsonl` for the "default" chat. Fixed by always merging legacy + modern for `default`, dedup by id.
- **Whole-page scroll.** Agent body had `min-height: 100vh`, letting messages grow page-tall instead of scrolling internally. Switched to `height: 100vh; min-height: 0; padding-bottom: var(--ds-8)` on the Screen, plus `overflow: hidden + min-height: 0` on body/pane. Messages scroll internally now.
- **Enter to send.** Composer commits on Enter; `Shift+Enter` inserts a newline.
- **Thinking bubble + word-by-word.** While the spawned task is pending, the assistant row renders a three-dot "thinking…" placeholder. When the reply lands, a streaming cursor advances at ~6 chars per 28ms (~200 chars/sec) until the body is fully painted.
- **Markdown rendering.** ChatMessage body is now run through `react-markdown` + `remark-gfm` when it's a string. Bold, lists, inline `code`, fences, tables all render. Raw HTML stripped by react-markdown's default policy.

### Avatar customization (under Identity)

Doug wanted operators to set vibe through a portrait, not just a generic initial circle. Lives under the Identity tab.

- **Image path.** Drop a jpg/png into the editor or click to pick. Inline crop frame (react-easy-crop, round shape, 1:1 aspect). Save runs a canvas-side resize to 256×256 webp @ 0.82 quality (drops most uploads under ~30 KB). `PUT /api/v1/agents/:name/avatar/image` lands the base64 payload at `<home>/agents/<name>/avatar.webp`. `GET` serves it; `DELETE` clears it.
- **DTO.** `toAgentDto` now emits `avatar_image_url: /api/v1/agents/<name>/avatar/image?v=<mtime>` when the file exists. Cache-busts via mtime.
- **AgentMark primitive extension.** New `imageUrl` prop with precedence `image > glyph > monogram`. New `.markImage` / `.markImg` CSS rules (object-fit: cover inside the circle, 1px hue-mixed border).
