## The arc, in order

### Morning: the regression and the strategic pause

Session opened reading the 2026-05-11 handoff: Grok-Jodin's first smoke
test had run "clean" but a follow-up scheduled task hallucinated a
completion message at 14:03 UTC with one LLM call and zero tool
calls. Plus a 13:58 brain log claimed playlists were created while
every Spotify write tool was failing. The pattern was the
narrated-completion-without-tool-call failure mode the handoff flagged
as outcome #3.

Diagnosis surfaced three real bugs underneath:
1. `spotify_search_tracks` returning 400 "Invalid limit" — SDK or
   Zod-default propagation issue.
2. `spotify_get_playlist_tracks` returning 403 "Bad OAuth request" —
   same class as the Feb-2026 SDK-staleness bug we patched yesterday;
   one more endpoint we missed.
3. `playlist_id` regex schema rejecting URI form — internal
   inconsistency in our own tool surface.

This is when the strategic pivot landed. Per `wiki/decisions/2026-05-11-platform-integration-pattern.md`,
we collapsed the 12 Spotify wrappers into `spotify_api` + the
server-side-only `spotify_set_playlist_cover`. SDK staleness becomes a
brain-note update, not a code change. The pattern is the same shape we
later applied to Discord and Slack.
