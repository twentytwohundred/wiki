### Epic 9: Tool system (Phase A, complete)

Spec drafted at [[09-tool-system]]. Doug signed off on three open product calls (wildcards in `tools:`, locked backoff/crash policy, no schema field for source pinning). Four-PR stack landed:

- **PR #81 ... Identity schema v5 + `mcp_servers` field.** Bumped Identity schema_version 4 → 5 with full migrator chain support. Added `mcp_servers: []` (each entry has name, transport, command, args, env: SecretRef map). Tool name regex relaxed to admit wildcards (`github.*`).
- **PR #82 ... stdio MCP transport via `@modelcontextprotocol/sdk` (1.29.0, MIT).** Per the integrate-over-build standing rule, wire-protocol framing + handshake live in the SDK; this module is the 2200-side adaptation (namespace prefix, ToolDefinition shape, error mapping). External tools default to `idempotency: 'destructive'`. Permissive args schema; the MCP server is the source of validation truth.
- **PR #83 ... Agent bootstrap wiring + wildcard expansion.** At Agent start, after baseline tools register, the process resolves SecretRefs, spawns each declared MCP server, registers their tools. The Identity's `tools:` array (mix of exact names and `<namespace>.*` wildcards) expands against the now-full registry. Shutdown closes each MCP handle.
- **PR #84 ... restart manager.** Wraps `spawnStdioMcpServer` with the locked Phase A policy: 200ms / 1s / 5s fast retries, then 30s × 2^n capped at 5min; Passive notification on first restart, Important after 5 consecutive failures; counter resets on successful spawn. Forwarding tool definitions throw "currently down (restarting)" during gaps. AgentProcess wires the manager instead of the raw spawn.

After this stack, an Identity declaring:

```yaml
mcp_servers:
  - name: github
    transport: stdio
    command: npx
    args: ['-y', '@modelcontextprotocol/server-github']
    env:
      GITHUB_TOKEN:
        source: env
        id: GITHUB_TOKEN_HOBBY
tools:
  - github.*
```

is enough for an Agent to use the GitHub MCP server's tools the moment it starts. No separate registration step.

- **MCP source pinning:** docs-only convention via npm version pinning; no schema field.
- **External MCP tools default to `idempotency: 'destructive'`** (most have real-world side effects).
- **Wildcards that match no registered tools drop silently** (operator may stage `github.*` before adding the github server).
- **PR stack workflow:** stacked PRs auto-close when their base is squash-merged; rebase + reopen as new PR is the recovery path.
