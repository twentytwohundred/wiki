### PR #94 — Epic 15 scaffold E: API client + WS + live Fleet screen

- **`src/lib/auth.ts`**: bearer-token bootstrap. `?token=` URL param → localStorage; subsequent requests carry the token via `Authorization: Bearer ...`.

- **`src/ws/useLiveSignal.tsx`**: connects to `/api/v1/ws` with bearer-via-query-param (browsers can't set Authorization on WS upgrades). Auto-reconnect with 250ms / 1s / 5s backoff. Maps inbound events to TanStack Query invalidations:

  - `notification.*` → `['notifications']`
  - `budget.threshold_crossed` → `['budget']`
- **`src/screens/fleet/FleetScreen.tsx`**: Mission Control variant. Three bands (NEEDS YOU / RUNNING / IDLE). Each row uses AgentMark + Pill + KV primitives.
- Runtime side: WS auth accepts `?token=<value>` in addition to `Authorization: Bearer`. `Supervisor.updateAgent` broadcasts `agent.status_changed` when state actually changes. `Supervisor.createAgent` broadcasts `agent.created`.
