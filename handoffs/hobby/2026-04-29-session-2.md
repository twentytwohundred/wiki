## Decisions locked today (session 2)

- **Workspace shape:** pnpm workspaces with root + `apps/*`. Runtime stays at root, no source moved. Each workspace member owns its own verify pipeline.
- **Web app stack:** Vite 5 + React 18 + TypeScript + Vitest + raw CSS variables. No Tailwind. No CSS-in-JS. No shadcn (pattern-lift only).
- **Phase A scope for Epic 15:** Fleet + Agent detail + Inbox + Command Palette. Onboarding/Pub/Budget defer to Phase B.
- **Auth at v1:** bearer token. Managed-service auth (sessions, SSO) is Epic 17.
- **API shape:** snake_case JSON, ISO-8601 UTC times, decimal-string money, cursor pagination, RFC-7807-shaped errors, JSON-Schema-driven type generation on the frontend side.
- **WebSocket transport** for live signal. Heartbeat every 30s. `Last-Event-Id` for backfill on reconnect. 5-minute backfill window.
- **Theme manifest:** single JSON, base-theme inheritance, three density modes, layout-region overrides per screen. A minimal theme is 25 lines.
- **Third theme (TBD):** deferred. Default Dark + Default Light at launch. Decision can land later without spec rework.
- **Cray test (Hobby's actual migration):** deferred this session; substrate work pulled focus.
- **Design-system folder location:** canonical home at `wiki/design-system/`. The standalone HTML lives outside the wiki at `design-system-archive/`.
