## Decisions locked today

- **Catch-up policy = SKIP** for missed scheduler firings. A supervisor returning from a 6h outage doesn't burst-fire 6 hourly schedules.
- **`run-once` is independent of cadence.** Manual fire enqueues a task but does not touch `last_fired_at` / `next_fire_at`.
- **5s minimum interval** at the schedule layer.
- **Brain is files first, index second.** SQLite FTS5 is rebuildable from disk; markdown files at `<home>/agents/<name>/brain/` are the source of truth. `2200 brain rebuild` is the explicit reconciliation hook.
- **Brain index lives under `state/`,** not `agents/<name>/`. Runtime-internal artifact in the runtime-internal namespace.
- **Brain Phase A scope = own brain only.** No shared brain, no cross-Agent reads, no link-graph traversal at this phase. Inline `[[slug]]` extraction happens at write time so Phase C's substrate is in place.
- **Bulk import preserves filename slugs and file mtimes.** Hobby's existing `feedback_*.md` / `project_*.md` / `user_*.md` filenames map directly to `feedback-*` / `project-*` / `user-*` slugs.
- **"We own" includes OpenSCUT.** Doug's clarification that owning the hosted register service satisfies the sovereignty principle. Path B is the only production path; Path A code removed from the v1 codebase.
- **Self-custody graduation is post-launch.** `POST /scut/v1/transfer` exists on OpenSCUT's side but 2200 doesn't exercise it until the website ships.
- **Per-displayName-per-day rate limit on registrations** is operator-visible via the `RegisterRateLimitError` notification body. Remediation: rename the Agent or wait until UTC midnight.
