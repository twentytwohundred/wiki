**PR #15 closed Epic 2.** Agent loop body + the five detector kinds + end-to-end task pipe.

- AgentLoop wraps `provider.complete()` + `dispatcher.dispatch()` in the iteration cycle. Tool calls encoded as fenced \`\`\`tool JSON blocks (portable across providers; native tool-calling APIs land in Epic 10 — see below). Maintains a bounded ring buffer of LoopEvents that feeds the detector substrate.
- Five detectors: `tool_repetition` (N=5 default), `no_progress` (50 iterations without brain write or non-self state transition), `tool_timeout` (120s), `cost_burst` ($5 in 10 minutes), `error_storm` (N=5 consecutive same-class failures). Pure functions over the event stream; evaluator runs them in fixed priority order; first to fire wins. On trip: trip record at `<brain>/.records/detector-trips/<trip_id>.md`, passive notification at `<state>/notifications/`, pulse-state file flipped to `redlined`, task transitioned to `blocked_on_detector`. `2200 agent resume <name>` flips back to `pending` and resets pulse to `green`.
- Task layer with locked `TaskFrontmatterSchema` (`schema_version: 1`, `idempotency`, `state`, `checkpoint`, `detector_block`, `outcome`, `error`). File-backed at `<home>/agents/<name>/tasks/<task_id>.md`.
- AgentProcess polls the task store on a 1-second tick when idle. Single-task at v1 per spec. Submitted task → poll picks up → loop runs → outcome on disk.
- Three new supervisor RPCs (`cli.task.submit`, `cli.task.list`, `cli.agent.resume`); the matching CLI commands are now functional (previously stubs).
- 261 tests across 25 files. 70 new tests across 6 files including a full vertical-slice end-to-end test (CLI submit → AgentProcess poll → loop → outcome on disk with full plan/run/perm records).

**Epic 2 done-when matrix.** Every spec criterion is satisfied except auto-resume from checkpoint on process restart (deferred to Epic 10 — the checkpoint payload format depends on the model-call shape, which depends on native tool-calling extensions to the LLMProvider abstraction).
