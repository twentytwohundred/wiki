# 2200 state of the runtime — 2026-06-18

First state snapshot since 2026-04-28. The 04-28 snapshot ([[state/2026-04-28]])
captured the runtime/identity/brain/pub/scheduler foundation; that all still holds.
This snapshot records the delta from the late-April foundation to the
**first-external-users** push of May–June. Full per-epic status is in
[[03-epic-map]]; the narrative is in [[handoffs/hobby/2026-06-17]].

- **Shipped version:** `2026.617.1412` on npm (`@twentytwohundred/2200-cli`, `latest`).
- **Node requirement:** `>=22`.
- **Release scheme:** CalVer `YYYY.M.D.HHMM` ([[decisions/2026-06-12-calver-versioning]]).
- **Install:** `npm install -g @twentytwohundred/2200-cli@latest && 2200 setup`, or the
  one-line `install.sh`. (2200.ai's hosted `install.sh` resync is a standing Simon
  follow-up.)

## Connectors (shipped in the npm package)

`dist/connectors/`: **discord, slack, telegram**. Each is a self-contained bundled
gateway (esbuild → CJS), launched by the `GatewayManager` with plain `node`. WhatsApp
remains dev-only.

## Baseline tool surface (per-Agent)

`src/runtime/tools/baseline/`: fs, shell, http, web, brain, time, pub, notification,
schedule, system, image, credential, shelf, task-delegate, agent-control, chat, plus
the per-connector send tools (discord, slack, telegram, whatsapp). Platform
passthrough tools under `tools/platform/`: discord, slack, spotify.

## Known-not-yet-reverified (the next test pass)

The Studio stability chain (keepalive overlay, Bartender-off, persistence, ambient
recovery) is committed and CHANGELOG-documented but **not independently re-verified on
a clean published install this session**. The verification checklist is in
[[handoffs/hobby/2026-06-17]]: Agents stay past 60s, show once by real name, chat
persists across restart, ambient/`@all` land, Telegram + Slack connect from a
published install.
