## Known gaps heading into the final push

From the 2026-07-01 four-agent QA sweep. Full ranked list + file:line in
[[handoffs/hobby/2026-07-01]]. Ordered by likelihood a first user or demo viewer hits
it:

**Tier 0 ... stranger-path blockers:**
- Fresh install never gets a Studio ... `ensureStudioPub` fires only at boot, never on
  the onboarding-confirm path. The first Agent has no room; its seeded orientation
  post targets `studio` and fails. Verified by hand.
- Provider failure mid-interview is swallowed ... onboarding "succeeds" with a dead
  Agent; `local` endpoint never reachability-checked on the web path.
- CLI-wizard API keys dead until a restart the wizard never performs.
- Main chat screen silently eats failed sends + spins "Thinking…" forever on Agent
  death.
- Name normalization throws unrecoverable 500s; no rename control in preview.

**Tier 1 ... security (transport edge; crypto/perms underneath are clean).**
Exploit-level detail is held out of this public doc and delivered to Doug directly
(issues are unpatched; instances bind non-loopback today):
- CRITICAL: default network-bind + bearer-transport posture ... hardening recommended
  before external hands. Install-contract change (Simon), Doug's call.
- A few auth-coverage / token-scope drifts and an OAuth discovery-metadata item at the
  HTTP edge.
- An operator credential-at-rest item flagged to Doug directly.

**Tier 2 ... shows on camera:** upgrade-UI regression mid-restart, `/dev/components` in
the palette, one-click schedule delete, six CSS vars pointing at non-existent
`--ds-danger/-error/-warning/-success` tokens, no runtime Node-version guard,
onboarding no-back / loses-state-on-refresh.
